Database dumps and complete site backups are written here first; the nightly hour, the staging limits and retention are in server.yaml. To move it: stop the panel services, move the folder, set backups.local_path in server.yaml, start them again.

Destinations

Any number of restic repositories: an SFTP server (a NAS, another box), an Amazon S3 bucket, or a folder this server can reach, on a disk here or a mounted share. Every complete backup and dump is copied to each hourly, recorded only after downloading it again and checking its contents, and kept by the repository counts on Settings. A copy here is let go only once every destination holds it.

Under /srv/repositories for this server's own data disk (beside the local copies, never among them), or under /mnt or /media for another disk or a mounted share: the places this server's services may write. A repository on a disk here keeps a deduplicated history at little cost and speeds restores, but dies with the server; on a mounted share it is an off-machine copy like any other.
