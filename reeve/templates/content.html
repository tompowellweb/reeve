Run a site tool

Commands run as the site owner. PHP, WP-CLI and Composer use this site's current PHP version; Symfony runs the application's bin/console. Commands may change files and databases.

For WP-CLI, enter arguments such as core update or plugin update --all (omit the leading wp). Select the WordPress directory and allow outgoing access for downloads.

The private site database is available by default. Commands run for up to 15 minutes; output is limited to 64 KiB. Do not start background services here.
