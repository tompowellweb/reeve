Certificates

Public needs the sites' names pointing at this server and ports 80 and 443 reachable. A name that is not there yet is served with the edge's own certificate until it is; each site's Domains section shows which. Saving a switch to public restarts the edge for a second and asks for every name at once.

Outbound mail

Direct delivery needs the provider to allow port 25 out and reverse DNS matching the hostname. Saving redeploys the relay and reattaches every PHP site.

Server profile

The defaults a new site gets: PHP memory and workers, the site's memory cap, what its database is sized for. Existing sites keep their values.

Backups

Keep complete site backups: every one for the first days, then one a day, one a week, one a month, for this many days each. Zero turns a tier off.

Changing the local folder needs the folder moved with the panel services stopped; the setting alone moves nothing.

PHP rebuilds

Each PHP branch is rebuilt with fresh packages on this schedule; sites roll to the new image with the previous one retained. The PHP page shows the runs.
